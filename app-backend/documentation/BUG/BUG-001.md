# BUG-001 — Cita persistida aunque falle su notificación

- Severidad: Alta
- Confianza: Confirmado
- Área: Backend / transacciones
- Archivo: `src/modules/appointments/appointments.service.ts`
- Símbolo: `AppointmentService.create`

## Problema
La cita se confirma antes de crear notificaciones. Si una notificación falla, la API devuelve 500 aunque la cita exista.

## Recomendación
Usar una transacción para estado indispensable o un outbox para efectos reintentables.

## Validación
Simular fallo de notificación: debe existir rollback total o éxito con reintento, nunca estado ambiguo.
